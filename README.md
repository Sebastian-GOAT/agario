Type-safe, lightweight, and fun — bring the simplicity of Scratch into real code.

## Running locally

1. Clone repo `git clone https://github.com/Sebastian-GOAT/agario.git`
2. Install dependencies `npm i`
3. Run server `npm run server`
4. In `src/global.ts`, change the URL to `http://locahost:3000`
5. Run the game `npm run dev`
6. Open the game on `http://localhost:5173`
